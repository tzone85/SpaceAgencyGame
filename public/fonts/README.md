# Game Fonts

This directory contains game fonts used by Stellar Command.

## Fonts Required

- `orbitron-bold.woff2` - Bold variant for headings and titles
- `orbitron-regular.woff2` - Regular variant for UI text
- `roboto-mono-regular.woff2` - Monospace font for data displays

## Font Sources

These are game-specific fonts that should be optimized for display in the game UI. Consider sources like:
- Google Fonts (Orbitron, Roboto Mono)
- FontSquirrel for web-optimized versions
- Custom game fonts for a unique aesthetic

All fonts should be in WOFF2 format for optimal web delivery.
